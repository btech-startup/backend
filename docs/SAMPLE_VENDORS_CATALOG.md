## 💻 Copy-Pasteable cURL Testing Suite

### 1. Get All Sample Vendors
```bash
curl http://localhost:5000/api/v1/user/sample-vendors
```

### 2. Search Vendors by Category
```bash
curl "http://localhost:5000/api/v1/user/vendors?category=PHOTOGRAPHY"
```

### 3. Retrieve Vendor Profile with Banking & Chatbot
```bash
curl http://localhost:5000/api/v1/user/vendors/70421caf-a7ef-4cad-9960-48ba6fabf7a7
```

### 4. Retrieve Vendor Verified Banking Info
```bash
curl http://localhost:5000/api/v1/user/vendors/70421caf-a7ef-4cad-9960-48ba6fabf7a7/banking
```

### 5. Initiate Chatbot Deal Negotiation
```bash
curl -X POST http://localhost:5000/api/v1/user/deals/chatbot \
  -H "Content-Type: application/json" \
  -d '{
    "vendorId": "70421caf-a7ef-4cad-9960-48ba6fabf7a7",
    "priceCardId": "pc-royal-decor-01",
    "clientName": "Sunita Mehra",
    "clientPhone": "+919911223344",
    "eventType": "Wedding Reception",
    "eventDate": "2026-11-28",
    "guestCount": 400,
    "offeredPrice": 75000,
    "userMessage": "Hello! Can you offer ₹75,000 for our 400-guest reception?"
  }'
```

### 6. Login as Vendor (OTP Flow)
```bash
# Step 1: Request OTP
curl -X POST http://localhost:5000/api/v1/auth/send-otp \
  -H "Content-Type: application/json" \

# Step 2: Verify OTP
curl -X POST http://localhost:5000/api/v1/auth/verify-otp \
  -H "Content-Type: application/json" \
  -d '{"phone": "+919876500001", "otp": "123456"}'
```
